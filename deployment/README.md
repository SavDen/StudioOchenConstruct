# Сервер Gemini для опубликованного редактора

Клиент Pages получает публичный адрес из pages.json. Токена в нём нет. Для отключённого API можно заменить конфигурацию на `{"mode":"static"}` и пересобрать Pages. Локальный редактор продолжает использовать API на своём origin.

Dockerfile запускает тот же исполнитель планов и геометрии на Node.js 24. Он использует готовые PNG-каталоги и не требует npm-пакетов. Контейнер работает от пользователя node; при размещении используются read-only filesystem, лимиты CPU/RAM и отсутствие опубликованных Docker-портов. Доступ снаружи предоставляет действующий HTTPS reverse proxy.

Пример сборки: `docker build -f deployment/Dockerfile -t studio-ochen-construct:<release> .`. Создайте отдельный серверный env по gateway.env.example с правами 600. Запуск передаёт его через `--env-file`, а не через параметры командной строки с ключами. Не добавляйте заполненный env в Git и Docker build context.

Для существующего Caddy перед прежним общим reverse_proxy добавляется отдельный маршрут:

```caddyfile
handle_path /studio-api/* {
    reverse_proxy studio-ochen-construct:8000 {
        header_up X-Studio-Client-IP {remote_host}
    }
}
handle {
    reverse_proxy gemini-api:8080
}
```

Остальные HTTPS-настройки и ограничения прежнего сайта сохраняются. До изменения нужно сохранить его конфигурацию и инвентаризацию контейнеров. Конфигурация проверяется через caddy validate, затем применяется через caddy reload без перезапуска остальных контейнеров. Если Caddyfile смонтирован отдельным bind-файлом, сохраняйте inode файла при обновлении. Восстановление — вернуть сохранённое содержимое и повторить reload.

AI_PUBLIC_HOST и AI_ALLOWED_ORIGINS задаются явно. Без них сохраняются прежние ограничения localhost. Публичный API принимает только точный разрешённый origin, отвечает на JSON preflight и не принимает браузерные credentials. Заголовок клиентского IP перезаписывает Caddy; сам порт backend не публикуется. CORS не является авторизацией для произвольных HTTP-клиентов. Дополнительно действуют лимиты: 4 запроса в минуту на IP, 12 в минуту и 2 одновременных на сервис, 200 запросов за UTC-день. Суточный счётчик хранится в памяти процесса и сбрасывается после его перезапуска. Квоты Google действуют отдельно.

Проверяйте /studio-api/api/ai-status с Origin опубликованного сайта, реальную генерацию во всех форматах, отклонение постороннего origin и исходный /health прокси. Контейнер backend должен быть healthy; ID и время запуска существующих сервисов должны сохраниться.

Активный контейнер studio-ochen-palette-f81f2f2ff618 запущен с теми же ограничениями; Caddy переключён после healthcheck и проверки цветовых ролей. Конфигурация прокси и VPN сохранена, их ID и время запуска не изменились. Исходники релиза: /opt/studio-ochen-construct/releases/palette-f81f2f2ff618. Секреты остаются в серверном runtime.env.
