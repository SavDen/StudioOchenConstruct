# Загрузка своей палитры

В редакторе: «Композиция» → «Цветовая схема» → «Загрузить палитру». Рядом находится готовый JSON-шаблон. Файл содержит только цвета, максимум 128 КБ. Неверный файл не изменяет текущую сцену.

Поддержаны JSON с восемью именованными ролями, JSON-массив цветов, HEX/TXT, CSS, SVG и GIMP Palette (GPL). Из CSS/SVG извлекаются только HEX-цвета: документ не исполняется и не добавляется в иллюстрацию. ASE/ACO и фотографии палитр не поддерживаются.

Для точного назначения используйте dist/palette-template.json. Роли:

| Ключ | Назначение |
| --- | --- |
| background.base | Основной цвет фона |
| object.primary | Основной акцент предметов |
| object.secondary | Второй акцент |
| object.tertiary | Дополнительный цвет |
| background.mid | Мягкий оттенок фоновых предметов и деталей |
| background.dark | Контуры и тени окружения |
| ink | Контуры и тени главных предметов |
| paper | Светлые участки предметов |

Для простого списка нужны минимум три цвета: фон, основной и второй акцент. Четвёртый задаёт дополнительный цвет; недостающие фоновые оттенки и контрастные контуры рассчитываются автоматически. При восьми цветах порядок соответствует таблице. Принимаются непрозрачные HEX #RGB и #RRGGBB. Расширенные списки содержат до 32 цветов, используются первые восемь. В CSS/SVG повторяющиеся цвета объединяются с сохранением первого появления.

После загрузки раскройте «Настроить цвета», чтобы уточнить любую роль и скачать итоговый JSON. Одна палитра управляет главными предметами, окружением и фоном. Геометрия, порядок, рисунок фона и камера сохраняются. Отдельной настройки цвета фона нет.

Палитра встроена в снимок сцены, автосохранение и JSON проекта. Каждая пара «формат + вариант» сохраняет свою схему по существующим правилам памяти. Новая генерация из сцены со своей палитрой получает её во всех девяти подготовленных сценах. Выбор исходной схемы оставляет последнюю пользовательскую палитру доступной для повторного выбора.

S/L относится к двум авторским размерам ассетов, включая окружение и фон. Это не формат холста: квадрат, горизонталь и вертикаль выбираются независимо. Перекраска и переключение S/L не растягивают исходные контуры.
