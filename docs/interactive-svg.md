# Интерактивный SVG

В редакторе доступны два экспорта:

- **Интерактивный SVG** — один автономный файл. Откройте его отдельной вкладкой браузера: внутри находится редактор и полная исходная библиотека. Для сохранения изменений скачайте «Интерактивный SVG» ещё раз.
- **Чистый SVG** — только итоговая векторная композиция, без интерфейса и сценариев. Его можно передать в Figma или использовать как изображение.

Интерактивный файл позволяет добавлять и искать предметы, собирать сцену по словам, перемещать, поворачивать, отражать, дублировать и удалять объекты; менять роль, видимость и порядок слоёв, S/L, формат и размеры холста, фон и палитру. Импорт собственной палитры и проекта JSON работает через выбор файла. Отмена и повтор действий доступны кнопками и с клавиатуры. В файле сохраняются независимые сцены всех форматов и вариантов.

Gemini доступен в основном сервисе. Автономный SVG работает без сетевых запросов и использует локальный подбор по словам. Правки в открытом файле находятся в памяти до повторного скачивания файла или проекта JSON; браузер не перезаписывает исходный файл автоматически.

Если вставить интерактивный SVG как обычное изображение, показывается векторная композиция. Для запуска редактора откройте сам файл в браузере. Мессенджеры и программы просмотра могут показывать только картинку.

Открытие локального файла, редактирование и повторное сохранение проверены в Chrome. Другие браузерные движки пока не проверялись.

## Устройство и сборка

`dist/standalone-export.js` сохраняет настоящие исходные SVG-группы в корне документа и добавляет данные проекта и загрузчик. Загрузчик создаёт редактор в изолированном iframe внутри SVG foreignObject. Редактор использует те же модули и интерфейс, что и сервис. Исходные пути не меняются и не растеризуются. В экспорт не входят серверная конфигурация и ключи.

`scripts/build_interactive_svg.mjs` собирает только публичные HTML/CSS/JS, исходную библиотеку и промпт. Конфигурация API заменяется на статическую. Встроенная политика запрещает сетевые запросы, sandbox не разрешает доступ к родительской странице или хранилищу сайта. При сохранении новая копия использует тот же шаблон редактора, поэтому файл не растёт рекурсивно.

Команда `npm run build:interactive` создаёт `dist/interactive-shell.js` и три интерактивных примера. Эти файлы не хранятся в Git. `npm start`, `npm run start:static` и `npm run build:pages` включают этот шаг. Сборка Pages также обновляет архив демонстрации; ссылки на файлы доступны рядом с примерами.
