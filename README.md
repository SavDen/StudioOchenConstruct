# studio-ochen-construct

Веб-сервис для сборки векторных иллюстраций из готовой библиотеки SVG. Помогает дизайнеру быстро подготовить композицию под нужную тему и формат, сокращая ручной подбор и расстановку предметов.

Пользователь вводит метафору, заголовок или названия компонентов. Gemini подбирает предметы и предлагает расположение, а движок собирает сцену из исходных SVG, сохраняя их контуры и пропорции.

Композицию можно отредактировать вручную, изменить слои, выбрать формат холста и набор S/L, применить готовую или загрузить свою палитру. Результат скачивается в редактируемом SVG, а проект сохраняется в JSON для дальнейшей работы.
