# Сборка — тестовый конструктор иллюстраций

Рабочий прототип без ИИ. Подбирает существующие предметы по названиям и ключевым словам, автоматически расставляет их и экспортирует редактируемый SVG.

## Запуск

Откройте dist/index.html в браузере. Файлы уже собраны, запросов к API нет. Для локального HTTP-запуска: python3 -m http.server 8000 --directory dist.

## Что проверить

- Введите «Свет знаний», «Финансы под контролем» или список «книга, телефон, наушники».
- Переключите S/L, формат и раскладку. Программа использует реальные варианты, а не растягивает один исходник.
- Выберите любую из трёх исходных палитр.
- Перетащите предмет. Через панель можно изменить роль, угол, порядок слоя, сделать дубликат или удалить.
- Скачайте SVG и откройте его в Figma: предметы остаются отдельными векторными группами.
- Сохраните проект JSON и откройте его обратно. Автосохранение действует в этом браузере.
- Неизвестные слова не создают новые предметы; можно выбрать их вручную из библиотеки.

## Архитектура

library/ содержит копию подготовленных SVG и неизменённые исходные экспорты. manifest.json связывает смысловой id предмета с размером S/L и ролью main/background. У SVG явные fill/stroke и data-атрибуты цветовых слотов.

scripts/build_data.py упаковывает каталог и SVG в dist/data.js. Приложение работает без сетевой загрузки элементов, поэтому его можно открыть как локальный файл.

dist/engine.js — независимое от DOM ядро: словарь ключевых слов и исключений, выбор предметов, фиксированные опорные раскладки, ограниченное разведение границ главных предметов, применение цветовых ролей и сборка итогового SVG. Ядро можно заменить или дополнить ИИ-подбором без изменения редактора.

dist/app.js — интерфейс, история изменений, указатель и клавиатура, настройка композиции, локальное сохранение и скачивание. В экспорт не попадают рамки выделения и направляющая под заголовок.

## Ограничения прототипа

Это подбор по словарю, а не понимание произвольных метафор. Все совпавшие явно названные предметы сохраняются; смысловой запрос выбирает до четырёх основных предметов. Дополнительный фоновый предмет включается настройкой.
Всего на холсте допускается до 32 экземпляров.
Используются три исходные палитры без генератора и ручного изменения цветов.
Размер изменяется для всей сцены. Внутренняя геометрия и относительные размеры исходных предметов сохраняются.
Главные предметы разводятся по прямоугольным границам в автоматической сборке. Фоновые могут перекрываться и обрезаться. После ручного перемещения пересечения разрешены.
Пустой экран и пазл у телефона — именно те версии, которые содержались в исходниках.
JSON-проект хранит ссылки на библиотеку и координаты, а не произвольные загружаемые SVG.

## Разработка и проверка

Зависимости для работы не нужны. Для повторной сборки данных нужен Python 3.

- python3 scripts/build_data.py — обновить встроенную библиотеку.
- node --test tests/engine.test.cjs — проверить подбор, раскладки, цветовые роли, безопасность проекта и сохранность контуров.
- node scripts/validate.mjs — синтаксис, тесты и примеры экспорта.
- node scripts/render_examples.mjs — растровые QA-превью трёх экспортов; нужен sharp. PNG не используются для итогового экспорта.

Разработка выполнена с Codex. Внутри приложения модели ИИ не вызываются.

## Границы проверки

Пройдены 13 проверок ядра, 24 сочетания раскладок и 120 случаев сохранности вектора и палитр. SVG-экспорт разобран XML-парсером и отрисован в трёх примерах. Проверка интерфейса в браузере недоступна: локальное управление браузером отключено, Mac заблокирован. Нативные скачивания, перетаскивание и фактическая мобильная раскладка требуют проверки в браузере.
